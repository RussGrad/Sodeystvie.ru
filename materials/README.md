# Материалы для an-sodeystvie.ru

Сложите файлы в подпапки — вёрстка подхватит пути из ТЗ по мере реализации фаз.

## Структура

| Папка | Содержимое |
|-------|------------|
| `hero/` | Фон hero (Иркутск, новостройка, интерьер), WebP + JPG |
| `team/` | Фото сотрудников 280×280+, имя в имени файла |
| `banks/` | Логотипы Сбер, ВТБ, Альфа, Дом.РФ, Газпромбанк, Росбанк, Открытие, Совкомбанк (PNG/SVG, прозрачный фон) |
| `blog/` | Обложки статей |
| `texts/` | Тексты блоков (why-us, how-we-work, team, reviews, CTA) |
| `social/` | Ссылки и иконки мессенджеров |

## Ссылки (скопировать в `public/.env` или передать разработчику)

Создайте файл `social/links.md`:

## Цифры для сайта

- Год основания: **2010** (уже в шапке)
- Лет на рынке / сделок / рейтинг 4.9 (250+ отзывов) → `texts/facts.md`

## После загрузки

1. Логотипы банков для блока «Партнёры» — копировать в `public/assets/banks/` (см. `public/assets/banks/README.md` для ипотеки).
2. Hero — положить в `materials/hero/`, разработчик перенесёт в `public/assets/hero/`.
