# Бизнес-цели и контекст

## Цели сайта

- [ ] **Лидогенерация**: получение заявок (звонок, форма, мессенджер) с понятной атрибуцией источника.
- [ ] **Доверие**: демонстрация экспертизы, реквизиты, лицензии (если применимо), кейсы/отзывы.
- [ ] **Каталог**: показ актуальных объектов с фильтрами и быстрым контактом по объекту (**обязательно в MVP**).
- [ ] **SEO/гео** (если в scope): видимость по целевым запросам и регионам.

*Заполнить приоритеты 1–3 по важности для агентства.*

## Целевая аудитория

| Сегмент | Потребности | Что сайт должен дать |
|---------|-------------|----------------------|
| Покупатель / арендатор | Подбор объекта, консультация | **Каталог** (новостройки/вторичка), быстрый поиск («Найти», «На карте»), **ипотека** (калькулятор), **отзывы**, контакты |
| Продавец / арендодатель | Продажа/сдача объекта | УТП агентства, **заявка** (модальное окно), сценарий «Продать/Сдать → Оставить заявку», **отзывы**, контакты |
| Партнёры / юр. лица | *(опционально)* | Контакты / реквизиты |

## Конкуренты и позиционирование

- Кратко: чем агентство отличается (ниша, география, тип объектов).
- Ссылки на 2–3 референса сайтов (плюсы/минусы) — *добавить по мере сбора*.
