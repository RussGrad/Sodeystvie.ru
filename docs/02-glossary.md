# Глоссарий

Термины для единообразия в ТЗ, контенте и интерфейсе.

| Термин | Определение |
|--------|-------------|
| **Объект недвижимости** | Единица каталога: квартира, дом, участок, коммерция и т.д. с набором атрибутов (цена, площадь, адрес/район, фото). |
| **Лид / заявка** | Обращение пользователя с контактами и контекстом (общая заявка или привязка к объекту). |
| **Каталог** | Раздел со списком объектов, фильтрами и карточками. |
| **Карточка объекта** | Страница одного объекта: медиа, характеристики, цена, CTA. |
| **УТП** | Уникальное торговое предложение — кратко на главной и в рекламе. |
| **MVP** | Минимально жизнеспособная версия сайта — объём первой поставки. |
| **ЧПУ** | Человекопонятные URL (без технических id в адресе, где возможно). |
| **БЭМ** | Методология вёрстки: блок — элемент — модификатор; в проекте — соглашение по классам HTML и SCSS ([04-functional-spec.md](04-functional-spec.md) §0). |
| **ПДн** | Персональные данные — обработка по политике и согласиям. |

## Роли (если появятся в проекте)

| Роль | Описание |
|------|----------|
| Гость | Неавторизованный посетитель. |
| Контент-редактор | Добавляет/редактирует страницы и объекты (зависит от CMS). |
| Администратор | Полные права в системе управления. |

*Дополнить терминами по специфике агентства (аренда/продажа, новостройки/вторичка).*
