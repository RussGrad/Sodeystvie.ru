## Общие

| ID | Критерий | Да/Нет |

| AC-G-01 | Сайт открывается по HTTPS без предупреждений браузера | |

## Формы заявок

| ID | Критерий | Да/Нет |
|----|----------|--------|
| AC-F-01 | Отправка невозможна без обязательных полей; показываются ошибки | |
| AC-F-02 | Без согласия на ПДн заявка не уходит (если так зафиксировано юристом) | |
| AC-F-03 | После успешной отправки пользователь видит подтверждение | |
| AC-F-04 | Заявка создаётся в **Bitrix24** (лид/сущность по настройке) — **проверить тестовой отправкой**; при включённом дублировании — проверить почту | |

## Закрытие приёмки

Промежуточно можно закрывать **AC-H-01** (каркас главной), затем **AC-H-02** (секции).

Итоговая приёмка — когда все релевантные строки, **включая блок каталога (AC-C-*)**, отмечены «Да» или зафиксированы допустимые отклонения письменно.
