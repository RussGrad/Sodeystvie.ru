# Фото команды (резерв)

**Основной источник:** CRM → раздел «Сотрудники» → колонка **«На сайте»**.

Сайт запрашивает `GET /api/public/team` и показывает сотрудников с включённым флагом `showOnSite`.

Эта папка и `public/data/team.json` — **резерв**, если CRM временно недоступна.

| Файл | Поле `id` в `team.json` (fallback) |
|------|--------------------------------------|
| `director.jpg` | `director` |

Форматы: JPG, PNG, WebP. Рекомендуемый кадр: квадрат, не менее 400×400 px.
