# Фото команды

Положите портреты в эту папку — они появятся на главной и в разделе «О компании».

| Файл | Поле `id` в `public/data/team.json` |
|------|--------------------------------------|
| `director.jpg` | `director` |
| `broker-1.jpg` | `broker-1` |
| `broker-2.jpg` | `broker-2` |
| `lawyer.jpg` | `lawyer` |
| `mortgage.jpg` | `mortgage` |

Форматы: JPG, PNG, WebP. Рекомендуемый кадр: квадрат или 3:4, студийный деловой стиль, не менее 400×400 px.

В `team.json` укажите реальные **имя**, **должность**, **стаж**, ссылки **telegram** и **whatsapp**.
