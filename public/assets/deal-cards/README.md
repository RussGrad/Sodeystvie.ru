# Фото для блока «Продать / Купить / Сдать / Снять»

Вертикальные кадры для главной страницы (секция под первым экраном).

| Файл | Сюжет |
|------|--------|
| `sell.jpg` или `sell.png` | Продажа: консультация, документы |
| `buy.jpg` / `buy.png` | Покупка: подбор с риэлтором |
| `rent-out.jpg` / `rent-out.png` | Сдача: ключи, договор |
| `rent-in.jpg` / `rent-in.png` | Аренда: просмотр квартиры |

Рекомендуемый размер: **560×720 px** (портрет), JPG или PNG.  
После замены: `npm run build:images` (WebP) и деплой.
