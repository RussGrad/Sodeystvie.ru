# Логотипы банков (ипотека)

Положите файлы сюда — они появятся в калькуляторе на `/mortgage/`.

## Имена файлов

Смотрите поле `"logo"` в `public/data/mortgage-banks.json`:

| Файл | Банк |
|------|------|
| `tbank.png` | Т-Банк |
| `metallinvest.png` | Металлинвестбанк |
| `domrf.png` | ДОМ.РФ |
| `mkb.png` | Московский кредитный банк |
| `uralsib.png` | Уралсиб |
| `sber.png` | Сбер |

Допустимы **PNG**, **SVG**, **WEBP**, **JPG**. В JSON укажите точное имя файла, например `"logo": "tbank.svg"`.

## Рекомендуемый размер

- **Высота:** 48–64 px (или SVG)
- **Фон:** прозрачный
- **Формат:** PNG или SVG

## Добавить новый банк

1. Сохраните логотип: `public/assets/banks/noviy-bank.png`
2. Откройте `public/data/mortgage-banks.json` и добавьте объект:

```json
{
  "id": "noviy-bank",
  "name": "Название банка",
  "abbr": "Н",
  "logo": "noviy-bank.png",
  "rateDelta": 0.1,
  "enabled": true
}
```

- `rateDelta` — надбавка к ставке программы (в процентах), для расчёта платежа в карточке.
- `enabled: false` — скрыть банк без удаления из списка.

Если файла нет или он не загрузился — показывается буква из `abbr`.
